# Retail Sales Analysis 📊

A portfolio-ready retail analytics project demonstrating **Python, Pandas, SQL and business intelligence concepts**.

## Project Overview
This project analyzes retail transactions to identify:
- Revenue and sales KPIs
- Top-performing products
- Category performance
- Regional performance
- Monthly sales trends
- Business opportunities

## Tech Stack
**Python | Pandas | SQL | Matplotlib | HTML/CSS**

## Key Results
- Total Revenue: ₹7,432,590.00

- Top Category: Electronics

## How to Run
1. Download/clone the repository.
2. Open `index.html` in a browser for the dashboard.
3. Install Python dependencies: `pip install pandas matplotlib`
4. Run: `python analysis.py`
5. Import `retail_sales.csv` into MySQL and run `queries.sql`.
